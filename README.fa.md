# دیوان میان‌بر

میان‌برهای صفحه‌کلیدتان در یک ابزارک روی دسکتاپ مک، و برنامه‌ای کوچک برای دیدن، جست‌وجو و ویرایش آن‌ها. به دو زبان فارسی و انگلیسی.

[English](README.md) · **فارسی**

![برنامه](docs/app.png)

![ابزارک در هر چهار اندازه](docs/widget.png)

## چه می‌کند

- **ابزارک دسکتاپ** در چهار اندازه. هر ابزارک یک بخش را نشان می‌دهد و اندازهٔ خیلی بزرگ دو بخش را.
- **دکمه‌های ورق زدن و بخش قبلی و بعدی** روی خود ابزارک، چون ابزارک‌ها اسکرول ندارند.
- **کلیک روی ابزارک** برنامه را روی همان بخش باز می‌کند، با همهٔ میان‌برها و جست‌وجو.
- **افزودن، ویرایش و حذف** میان‌برها و بخش‌ها، با دکمه برای علامت‌هایی مثل ⌘ و ⌥ و فلش‌ها.
- **جابه‌جا کردن بخش‌ها** با کشیدن و رها کردن در منوی کناری.
- **میان‌برهای پایهٔ مک** از اول آماده‌اند و بقیه را خودتان اضافه می‌کنید.
- **دنبال کردن یک فایل:** اگر میان‌برها را در فایلی جای دیگر نگه می‌دارید (مثلاً مخزن تنظیمات)، برنامه همان را می‌خواند، تغییراتش را دنبال می‌کند و ویرایش‌هایتان را در همان ذخیره می‌کند.
- **ورود و خروجی گرفتن** با همان قالب فایل.
- **تم روشن، تیره یا خودکار** و **زبان فارسی یا انگلیسی** با دکمه‌های بالای پنجره. در فارسی کل پنجره راست‌به‌چپ است.

## نصب

با هوم‌برو این دستور را اجرا کنید:

</div>

```sh
brew install --cask codingwithsaeed/tap/shortcut-divan
```

<div dir="rtl">

بعد برنامه را یک‌بار باز کنید. سپس روی دسکتاپ راست‌کلیک کنید، «ویرایش ابزارک‌ها» را بزنید و «دیوان میان‌بر» را اضافه کنید. برای به‌روزرسانی:

</div>

```sh
brew upgrade --cask shortcut-divan
```

<div dir="rtl">

یا به‌صورت دستی:

۱. فایل نصبی را از [صفحهٔ انتشارها](../../releases/latest) بگیرید و برنامه را به پوشهٔ برنامه‌ها بکشید.

۲. برنامه با حساب توسعه‌دهندهٔ اپل امضا نشده، پس مک بار اول بازش نمی‌کند. به تنظیمات سیستم، بخش حریم خصوصی و امنیت بروید و کنار اسم برنامه روی «باز کردن در هر صورت» بزنید. یا این دستور را در ترمینال اجرا کنید:

</div>

```sh
xattr -dr com.apple.quarantine "/Applications/Shortcut Divan.app"
```

<div dir="rtl">

۳. برنامه را یک‌بار باز کنید و ابزارک را مثل بالا اضافه کنید.

برنامه به نسخهٔ ۱۴ مک یا جدیدتر نیاز دارد.

## میان‌برهای شما

میان‌برها در این فایل ذخیره می‌شوند، هر میان‌بر در یک خط، تا با دست هم راحت ویرایش شوند:

</div>

```
~/Library/Application Support/Shortcut Divan/shortcuts.json
```

```json
{
  "sections": [
    {
      "title": "macOS",
      "accent": "iris",
      "rows": [
        { "keys": "⌘␣", "desc": "Spotlight search" }
      ]
    }
  ]
}
```

<div dir="rtl">

رنگ هر بخش یکی از این‌هاست، از رنگ‌های رزه‌پاین: `love` و `gold` و `rose` و `pine` و `foam` و `iris`. علامت `␣` به شکل کلید فاصله نشان داده می‌شود.

برای نگه داشتن میان‌برها در جای دیگر، از منوی فایل گزینهٔ دنبال کردن یک فایل میان‌بر را بزنید.

## زبان

برنامه با زبان سیستم باز می‌شود. برای عوض کردنش، از دکمهٔ کرهٔ زمین در بالای پنجره یا از تنظیمات برنامه، فارسی یا انگلیسی را انتخاب کنید. ابزارک هم همان زبان را می‌گیرد.

## ساختن از روی کد

به ایکس‌کد و ابزار ساخت پروژه نیاز دارد:

</div>

```sh
brew install xcodegen
./scripts/install.sh
```

<div dir="rtl">

این اسکریپت برنامه را می‌سازد و در پوشهٔ برنامه‌های خانگی شما نصب می‌کند.

## انتشار

با ساختن یک انتشار در گیت‌هاب، برنامه ساخته می‌شود و فایل نصبی به انتشار اضافه می‌شود. فایل هوم‌برو هم در مخزن `homebrew-tap` خودکار به‌روز می‌شود:

</div>

```sh
gh release create v1.1.0 --target main --generate-notes
```
